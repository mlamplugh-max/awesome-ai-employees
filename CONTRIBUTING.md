# Contributing

Pull requests are welcome. Keep it to **one entry per pull request** so each can be checked on its own.

An entry is accepted when it has:

1. A link the reviewer can open (no paywalls, no redirects to a sign-up wall).
2. One factual line in the list's format: `- [Name](url) - Description.`
3. A source and year inline for any number, statistic or quotation.
4. No superlatives, no rankings, no "best" — describe what the thing does.

If you have a commercial interest in an entry (you work for, invest in, or are paid by the vendor), say so in the pull request. Entries are listed alphabetically within a section; nothing is ranked.

Entries are removed when the link stops resolving, the product is discontinued, or the description can no longer be verified against the source.

By contributing you agree that your contribution is released under [CC0 1.0](./LICENSE).
